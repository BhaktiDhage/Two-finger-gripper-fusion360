# 🤖 Two-Finger Gripper: End Effector (Fusion 360)

A two-finger gripper end effector designed, constrained and assembled in
Autodesk Fusion 360. Built as a learning project in CAD modelling, joint
motion types and assembly design.

## 📖 About
This project is a two-finger gripper meant to work as the end effector of a
robotic arm. The focus was on getting the sketches, parts and joints right so
that every component moves only the way it is supposed to.

It took about four hours of deleting and redrawing one stubborn sketch before
everything finally came together. 😅

## ✨ Features
- Fully modelled parts for the gripper body and fingers
- Assembly built with proper joints (not just parts placed in space)
- Joint motion restricted to the intended degrees of freedom
- Clean, parametric sketches that are easy to modify

## 🛠️ Tools Used
- Autodesk Fusion 360
